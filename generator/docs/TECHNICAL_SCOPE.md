# GEN-R1 — Candidate code, not a physical test

Owner mission: actual physical acoustic + EM generators. Bureau owns research, metrology and certification. Prior CSV/import/ledger R29–R32 prototypes remain secondary.

The CoreAudio implementation uses native Apple AudioQueue but is unreachable through the R1 public function. The code is not calibrated or tested on Mac Intel, and cannot prove acoustic pressure, safety or emitted output.

No EM device or transducer is identified. The EM API explicitly refuses all emission. It will only be implemented for a specifically identified permitted device with independent safety cut-off and regulatory review. There are no universally safe emitted power or frequency parameters.

Software tests do not simulate physics or certify emissions. No data fixtures are presented as experimental results.
