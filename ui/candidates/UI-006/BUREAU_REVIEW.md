Valeurs calculées uniquement sur la dernière fenêtre native reçue, y compris les fenêtres courtes ; 0 est affiché -inf dBFS et aucune valeur indisponible n'est remplacée par une mesure. Pas de crête/RMS sur l'ensemble de la session revendiquées. L'anneau suit le rapport traité/attendu, non une animation fictive de progression. Les transitions CSS lissent seulement l'apparence des segments, respectent la préférence de mouvement réduit.
