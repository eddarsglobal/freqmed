## Source numérique réelle
Le petit exécutable macOS lit les métadonnées CoreAudio en lecture seule (collecteur PLATFORM-07 épinglé) et réutilise exactement le moteur C PLATFORM-09, les sessions et le Guardian. Il calcule un bloc de 4096 échantillons de commande numérique en mémoire si le profil est admissible ; il ferme la session et vérifie Guardian OFF. Les paramètres fixes du bloc de qualification sont indiqués dans la trace, distincts des brouillons des cadrans. Le fichier HTML local généré contient ce bloc numérique et ses métadonnées ; aucune donnée de microphone, aucun WAV ni flux audio. Il s'agit d'une trace de commande réellement calculée, pas d'une mesure, d'une simulation physique, d'un dispositif certifié ou d'une acquisition live. Si le profil est indisponible, aucun bloc ne s'affiche. Le graphique uPlot permet le zoom et l'inspection de ce bloc. Aucun lien des cadrans au moteur ni commandes physiques : START/STOP restent désactivés, pas d'autorisation.
24 sources historiques vérifiées par le runner sur Darwin, plus UI-001 et les 3 blobs uPlot. Compilation temporaire, suppression normale du binaire. Python >=3.9, Git, compilateur C11 et frameworks système ; pas d'installation supplémentaire. Windows/Linux : assemblage HTML possible, export natif non raccordé.
