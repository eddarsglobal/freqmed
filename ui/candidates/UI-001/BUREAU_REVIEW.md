# UI-001 — Precision Instrument Design System
Lien décisionnel : issue #43. Candidat isolé sur le commit PLATFORM-13, aucune modification de main, RoadMap, moteur C ou versions V4/V5. P5.01 reste PENDING. Revue B09/B08/B07/B04/B10 proposée, non rendue indépendamment.

## Livrable
FREQMED Instrument Kit (FIK) : interface HTML/CSS/JavaScript autonome, avec tokens de thème, surfaces instrumentales en relief, trois cadrans réutilisables (data-knob), réglage par glissement vertical souris/tactile, clavier et saisie exacte, fader lié au niveau numérique, cadran central, navigation acoustique/EM, moniteurs d'oscilloscope/spectre/spectrogramme, zoom de grille, vu-mètres sans données, état matériel déconnecté, remise à zéro du brouillon. Les valeurs de commande sont des brouillons UI uniquement, sans envoi au moteur. Les limites des champs sont des bornes d'édition de cette maquette, pas des limites physiques validées. Les moniteurs et vu-mètres n'affichent aucune mesure fictive. START/STOP désactivés car aucun runtime n'est connecté ; il n'existe aucune commande de matériel dans ce candidat. L'état déconnecté ne prétend pas confirmer l'état physique des appareils. Le contrôle d'arrêt du produit final relèvera du Guardian natif.

## Architecture et licences
Première étape sans dépendance JS tierce, sans npm ni compilation : CSS et API DOM standard ; zéro CDN, accès réseau désactivé par CSP, aucun Web Audio, aucune acquisition. Code candidat Apache-2.0, navigateur dépendance de plateforme. React/TypeScript, React Aria, PixiJS, uPlot et Tauri restent des candidats de UI-ARCH-01, non installés ni adoptés dans UI-001. Cette décision réduit les contraintes de qualification du premier kit et permet son évaluation dans Safari Intel. La migration et la séparation en bibliothèque TypeScript distribuable seront décidées après essai visuel et audit des dépendances. Aucune prétention à 60 fps ni à une compatibilité native déjà démontrée.

## Localisation et accessibilité
35 clés de traduction par langue, EN FR DE AR ES PT HR IT ZH KO, RTL arabe, trois thèmes, responsive, clavier, états aria et préférence réduction des animations. Les libellés techniques fixes et quelques aria-labels restent en anglais ; la localisation complète et les tests avec lecteurs d'écran restent à effectuer. Les couleurs, interactions tactiles, rendu et contraste doivent être vérifiés sur le vrai Mac.

## Qualification
Source exacte épinglée et vérifiée par qualify.py (11 contrôles statiques). Interface : bouton UI check exécute 23 contrôles DOM et restaure le brouillon/les sélections ; résultat visible et JSON dans console. Pas de test d'émission, d'acquisition, de rendu physique ou d'événement CoreAudio. Les contrôles DOM ne remplacent pas la vérification visuelle ni les essais pointeur/tactile réels. Les sources V4/V5 n'ont pas été retrouvées dans main ou les branches nommées consultées ; leur inventaire local reste nécessaire avant toute migration officielle. Aucun rôle Bureau présumé pourvu. Aucun changement aux autorisations physiques. Aucun achat ni installation imposé.
